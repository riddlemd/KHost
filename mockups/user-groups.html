Static, non-interactive reference for the user groups and permissions feature. Switch tabs to browse each screen.

/settings/user-groups-manager — lists every user group defined for the venue, its description, and the permission badges it grants. The search box filters rows client-side; the pencil/trash actions open the edit dialog (Screen 2) or a delete confirmation.

Ticking Admin (all permissions) dims and disables the entire permissions table below it — an admin group implicitly has every permission, so the individual checkboxes stop mattering.
