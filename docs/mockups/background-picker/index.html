The folder, so a venue can build their own

A pack is a folder of clips. Drop one in and it is a background; the file name is its name. Put a picture of the same name beside it and that becomes the still the venue picks by. There is nothing to author and nothing that can fall out of step with the files.

Folder

~/karaoke/backgrounds/
  amber.mp4     ← a background, named "amber"
  amber.jpg     ← its still
  violet.mp4
  violet.jpg
  aurora.mp4    ← no still: picked by name
  archive/      ← ignored, packs are flat

  • The file name is the name. Rename the file to rename the background; nothing else knows about it.
  • A still is optional — same name, picture extension, beside the clip. Without one the venue picks by name alone.
  • The loop has to wrap seamlessly. Crossfade the tail back over the head; a clip that simply ends cuts hard every time it repeats.
  • Keyframes every 2 seconds, matching the host's segment length, or the render cannot be cut for streaming without re-encoding.
  • Keep the lyric band dark. The renderer draws a scrim there, but a clip that is bright across the bottom will still fight the words.
  • Two clips may share a name — amber.mp4 and amber.mov are two backgrounds, which is why the venue stores the extension too.

Where it landed

06 with a checkbox on each tile, which is 06 and 09 folded together. Merging them removed the mode control entirely: ticking nothing is the black background, so there is no separate on/off to explain and no default to backfill.

The manifest went too. Names come from file names and a still is whatever picture sits beside the clip, so a pack is a folder you copy files into — nothing to author, nothing that can fall out of step. The cost of that is real and worth stating: a folder carries no credit, so a pack containing third-party footage has nowhere to attribute it.

09's curation came along for free in the merge. 03's folder row is still needed — the venue has to name the folder somewhere.
